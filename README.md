# Mercadinho Web

Projeto desenvolvido para a disciplina de Desenvolvimento Web.

## Descrição

Sistema web de mercadinho desenvolvido em Java utilizando Servlets e JSP.

O sistema permite o gerenciamento de produtos e simula um carrinho de compras, possibilitando a adição de itens e o cálculo automático do valor total da compra.

## Tecnologias Utilizadas

- Java
- JSP
- Servlets
- HTML
- CSS
- Apache Tomcat

## Funcionalidades

- Cadastro de produtos
- Exibição de produtos
- Adição de itens ao carrinho
- Cálculo do valor total da compra
- Controle de sessão do usuário

## Estrutura do Projeto

- Model: regras de negócio
- Servlet: controle das requisições
- JSP: interface do usuário
